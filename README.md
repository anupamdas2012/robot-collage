# The Robotics Industry on GitHub

A single self-contained web page that indexes the **top ~600 open-source robotics projects on GitHub**
(discovered live from the GitHub API, ranked by stars) and visualizes the field three ways:

- **📈 Growth & Analytics** — how the industry compounded over time (cumulative projects & stars,
  2010→present), most-starred projects, projects by country, language and sub-field, plus external
  job-market context.
- **🖼️ Project Collage** — all 600 projects packed into one screen; a **radial magnifying lens** follows
  the cursor, bulging the tile underneath while neighbors distort like glass (deterministic, frame-rate-independent motion).
- **🕸️ Topic Explorer** — a **3D force-directed graph** (TRON-style neon glow, depth-of-field, arc
  connectors) clustered by sub-field and linked by shared topics (nearest-neighbor). Node size =
  contributor count; a **trending heatmap** of blended metaball blobs overlays the graph. Drag to orbit,
  scroll to zoom, click a node to turn the "planet" so it faces you, and **type to reshape the network**
  (matches stay, the rest fall away).

Everything is one `index.html` with the data inlined — no build step, no server, works offline (the
project thumbnail images and the live page both hotlink GitHub's social-preview endpoint; a generated
SVG fallback covers any image that fails to load).

## How the data is produced

The page is static, but the data is generated by a small pipeline in `tools/` (needs `gh`, `jq`, `python3`):

```bash
bash   tools/collect.sh        # search 30+ robotics topics on GitHub, dedupe, keep top 600 by stars
python3 -I tools/select.py     # filter the pool to genuine robotics projects (drops CS/ML megalists, bots)
bash   tools/fetch_owners.sh   # look up each owner's profile location -> country
bash   tools/fetch_contrib.sh  # approximate contributor count per repo (project size)
python3 -I tools/build.py      # compute analytics + trending, inject the data into index.html
```

`tools/build.py` only replaces the JSON inside `<script id="robo-data">`, so re-running it preserves the app.

## Caveats

- **Country** is inferred from each owner's public GitHub profile location (~55% set); the rest are "Unknown".
- **Trending** is a momentum *proxy* (lifetime star-rate weighted by recent push activity) — GitHub does not
  expose per-repo star history at this scale.
- **Contributors** come from the contributors API (anonymous included), used as a proxy for project size.
- **Job-market numbers** are external context cited from the Stanford AI Index / Lightcast, not from this dataset.
- "Every robotics repo on GitHub" is hundreds of thousands; this is the top slice by stars.
